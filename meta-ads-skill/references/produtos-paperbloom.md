- Votacao interativa em tempo real (Menino ou Menina)
- Dashboard de votos ao vivo com contagem e porcentagem
- Galeria com ate 5 fotos (ultrassom, barriga, casal)
- Mensagens dos convidados
- QR Code exclusivo para compartilhar
- Funciona presencial + remoto simultaneamente
- Revela resultado para todos juntos

## Notas Importantes para Anuncios

1. **Precos dinamicos:** Os precos podem mudar via painel admin. Sempre verificar o preco atual antes de publicar copy com preco.
2. **Pixel obrigatorio:** Configurar pixel da Meta no site antes de campanhas de conversao.
3. **Teste gratis:** Esse e um diferencial importante — o cliente cria a mensagem, ve como fica, e so paga no checkout.
4. **Entrega instantanea:** Apos o pagamento, o link/QR Code chega por email imediatamente.
